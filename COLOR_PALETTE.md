# SAH Color Palettes

Official Color System 1.0 for SAH Group and each company brand.

Use these values as the source of truth when theming pages. Parent (group) routes use the **SAH Group** palette. Company homepages and related pages use that company’s palette.

**Developers:** for changing or adding themes in code, see [`docs/theming.md`](./docs/theming.md).

| Brand | Route / scope | Theme id |
| --- | --- | --- |
| SAH Group | `/`, shared parent pages | `group` (default `:root`) |
| SAH Human | `/sah-human`, `/coaches`, `/courses` | `human` |
| SEERA | `/seera` | `seera` |
| SAH Nexus | `/sah-nexus` | `nexus` |
| SAH Sponsor | `/sah-sponsor` | `connect` |
| LEGO by SAH | `/lego-by-sah` | `lego` |
| SAH Impact | `/sah-impact` | `impact` |

## Implementation notes

- **How-to for developers:** [`docs/theming.md`](./docs/theming.md).
- Group tokens: `src/styles/design-tokens.css` (`:root`).
- Company skins: `src/styles/brand-themes.css` via `data-theme` on `<html>` (`human`, `seera`, `nexus`, `connect`, `lego`, `impact`).
- Accent registry (orbit/cards/programs): `ENTITY_UI_COLORS` in `src/lib/brand-themes.ts` (applied by `getContent()`). Sponsor UI accent uses Dark Slate `#2B2F36` where Silver Gray is too light for text.
- Route → theme FOUC map is derived from `COMPANY_ROUTES` via `getCompanyThemeSlugMap()` — do not hardcode a second map.
- Do not invent hex values outside these sheets; map UI roles only to colors listed above.
- **Hard rule:** every color in CSS/UI must be a sheet hex or `color-mix` / opacity of a sheet token (`var(--deep)`, `var(--gold)`, `var(--white)`, etc.). No external reds, pure black `#000`, or legacy greens.
- Group has no Pure White — `--white` is Off White `#F8F6F4` on Group; company themes that list Pure White set `--white: #FFFFFF`.
- Error/danger UI uses deep brand tones (no red in the sheets), not off-palette red.
